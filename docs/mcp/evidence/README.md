# MCP evidence provenance

- `miura-report.json` and `miura-simulation.png` are historical, pre-hardening
  evidence. **The original MCP 0.55 request reached only 0.55%, not 55%.** Its
  simulation execution/convergence numbers cannot substantiate a 55% pose.
- `hardening/miura-report.json` and `hardening/miura-55.png` supersede that
  simulation evidence with explicit effective target and attainment residuals.
- `hardening/public-probes.json` and `hardening/hinge-55.*` verify the correctness
  fixes through the running desktop's public MCP transport.
- `astra-first/` preserves a curated, independently chosen bird-base design and
  blind evaluation. Its simulation limitation was the first independent evidence
  of the unit mismatch; do not treat its pre-fix simulation image as a final pose.

- `astra-fixed/` contains the independent 38-call Ginkgo-shell evaluation,
  editable design, verified substantial-fold mesh/image and rejected short-budget
  image. `astra-interrupted/` records the intervening infrastructure interruption.

Raw multi-megabyte agent transcripts and redundant MCP payload dumps remain in
ignored local `artifacts/` directories. See [the report](../hardening.md) for
classification, limitations and validation.
